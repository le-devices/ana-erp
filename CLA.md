- **Contribuição**: qualquer obra que Você envia ao Fornecedor para inclusão no projeto — código, testes,
  especificações, documentação, traduções, imagens, dados de pacotes de regras —, por pull request, patch,

## 9. Contribuição em nome de pessoa jurídica
Uma empresa pode aceitar este termo para todos os seus empregados e prestadores, indicando ao Fornecedor quem
está autorizado a contribuir em nome dela e mantendo essa lista atualizada. As contribuições dessas pessoas
ficam cobertas pelo termo aceito pela empresa.

## 10. Como aceitar
Você aceita este termo ao comentar no seu primeiro pull request:

A verificação automática do pull request registra o aceite (usuário do GitHub, data, versão do termo). Uma nova
versão do termo vale só para contribuições enviadas depois que Você a aceitar.
